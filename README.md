# To-Do List + Pomodoro Timer 🐰

Web sederhana untuk mengatur daftar tugas (to-do list) simple sekaligus fokus belajar dengan timer metode Pomodoro.
Dibuat dengan **PHP, CSS, dan JavaScript**, dilengkapi desain lucu warna soft pink-biru.

## ✨ Fitur

* Tambah, centang, dan hapus tugas
* Timer Pomodoro (25 menit fokus, 10 menit istirahat)
* Pause & reset timer
* Alarm otomatis saat waktu habis
* Animasi kelinci 🐰

## 🚀 Cara Menjalankan

1. Clone repo:

   ```bash
   git clone https://github.com/username/todo-pomodoro.git
   ```
2. Masuk ke folder project:

   ```bash
   cd todo-pomodoro
   ```
3. Jalankan dengan **PHP server lokal**:

   ```bash
   php -S localhost:8000
   ```
4. Buka di browser:

   ```
   http://localhost:8000
   ```

## 📂 Struktur Project

* `index.php` → halaman utama
* `style.css` → styling soft pink-biru
* `script.js` → logika to-do list & timer
* `alarm.mp3` → suara alarm sederhana

## 📝 Catatan

* Project ini tidak menggunakan database, semua data hanya tersimpan sementara di halaman.
* Untuk penggunaan jangka panjang, bisa ditambahkan penyimpanan (misalnya `localStorage` atau database MySQL).
